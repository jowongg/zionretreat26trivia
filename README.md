# 🎮 冷知識 Trivia 大挑戰

A Kahoot-style trivia game with 50 quirky-knowledge questions in Cantonese Chinese, covering five categories: animals, Christianity, history, food, and geography.

## Play

🎯 **Play online:** https://jowongg.github.io/zionretreat26trivia/trivia_game.html

Or open [`trivia_game.html`](./trivia_game.html) locally in any modern browser — no server, build step, or dependencies required.

## Features

- **50 questions** across 5 categories
- **Kahoot-style UI** with four colored answer buttons (red / blue / yellow / green)
- **Three difficulty tiers** — 簡單 (easy), 中等 (medium), 困難 (hard) — color-coded on the main menu
- **Three-page flow**: main menu → question → result (correct/wrong)
- Progress saved in `localStorage` (✓ marks on answered questions, reset button to start over)
- Mobile-responsive layout
- Correct answer + explanation revealed only on correct answers; wrong answers prompt a retry from the home page

## Files

- `trivia_game.html` — the full game (single self-contained HTML file)
- `trivia_50_final.md` — source markdown with all 50 questions, options, correct answers, and explanations

## Categories

- 🐾 **動物類** (Animals) — Q1–9
- ⛪ **基督教 / 教會類** (Christianity / Church) — Q10–19
- 📜 **歷史類** (History) — Q20–30
- 🍔 **食物類** (Food) — Q31–40
- 🌍 **地理 / 雜項類** (Geography / Misc) — Q41–50
